# 108 課綱社會領域（國中第四學習階段）知識矩陣

## 架構說明

社會領域統整歷史、地理、公民與社會三科的學習內容。學科知識以「學習內容」分科列舉，共通能力則以「學習表現」統整呈現。

| 軸向 | 內容 | 說明 |
|------|------|------|
| **Y 軸：學習表現** | 社（共通）、歷、地、公 | 理解思辨、態度價值、技能行動 |
| **X 軸：學習內容** | 歷史／地理／公民與社會 | 分科條列之核心知識 |

```
編碼規則：
  學習表現：{科目代碼}{認知層次}-{階段}-{流水號}
    例：社1a-Ⅳ-1（社會領域、理解思辨、第四階段、第1條）
  學習內容：{科目代碼}{主題}-{階段}-{流水號}
    例：歷Ba-Ⅳ-1（歷史、B主題a次主題、第四階段、第1條）
```
