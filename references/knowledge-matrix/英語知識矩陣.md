# 108 課綱英語文領域（國中第四學習階段）知識矩陣（修正版）

## 架構說明

英語文領域以聽、說、讀、寫、語言能力綜合應用、學習興趣與態度、學習方法與策略、文化理解、邏輯思考判斷與創造力為 Y 軸；語言知識、溝通功能、文化與習俗、思考能力為 X 軸。

| 軸向 | 內容 | 說明 |
|------|------|------|
| **Y 軸：學習表現** | 聽／說／讀／寫／語言能力綜合應用／學習興趣與態度／學習方法與策略／文化理解／邏輯思考判斷與創造力 | 語言溝通與應用能力 |
| **X 軸：學習內容** | 語言知識／溝通功能／文化與習俗／思考能力 | 語言系統知識與溝通文化 |

```
編碼規則：
  學習表現：{技能代碼}-{階段}-{流水號}
    例：1-Ⅳ-3（聽、第四階段、第3條）
  學習內容：{主題代碼}-{階段}-{流水號}
    例：Ac-Ⅳ-4（字詞、第四階段、第4條）

前綴標記（顯示於代碼前方）：
  ◎  = 重複出現在不同階段的學習表現
  *  = 較高階的適性選取表現（非強制）
  *◎ = 兼具上述兩種性質
```
