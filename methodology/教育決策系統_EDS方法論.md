# 教育決策系統（Educational Decision System, EDS）方法論

## 一、核心概念

教育決策系統（Educational Decision System, EDS）是一套基於課程綱要與評量數據，支援教學與學習決策的方法論框架。

### 1.1 問題意識

現行教育現場面臨三個核心問題：

1. **課綱與評量的斷層**：教師與學生不易將課綱抽象的能力指標，對應到具體的評量試題
2. **決策的經驗依賴**：教學調整與學習策略多仰賴個人經驗，缺乏結構化的數據支撐
3. **跨科目的可比性**：不同科目間的學習進展難以統一比較與整合

### 1.2 EDS 的解決方案

EDS 透過三層架構解決上述問題：

- **知識表徵層（Knowledge Representation）**：將課綱學習內容編碼為結構化的知識矩陣
- **評量連結層（Assessment Linkage）**：將試題對應到知識矩陣，建立雙向連結
- **決策引擎層（Decision Engine）**：基於知識矩陣與試題標註，產出教學與學習決策

## 二、知識矩陣設計原則

### 2.1 編碼原則

知識矩陣採用三層編碼結構：

```
科目碼 - 學習領域碼 - 學習內容編碼
  │         │             │
  國: C1   N-7            N-7-1
  英: E2   S-9            S-9-2
  數: M3   G-8            G-8-3
  ...
```

### 2.2 欄位結構

每筆知識矩陣記錄包含：

| 欄位 | 說明 |
|------|------|
| 科目 | 所屬科目（國文/英文/數學/社會/自然） |
| 年級 | 適用年級（7/8/9） |
| 學習領域 | 課綱學習領域編碼 |
| 學習內容編碼 | 課綱學習內容編碼 |
| 學習內容說明 | 課綱原文說明 |
| 學習內容細項 | 可教學/可評量的具體知識點 |
| 認知層次 | 記憶/理解/應用/分析 |
| 備註 | 補充說明 |

### 2.3 認知層次分類

採用修訂版 Bloom 認知層次（Anderson & Krathwohl, 2001）：

| 層次 | 說明 | 會考對應 |
|------|------|---------|
| 記憶（Remember） | 回憶事實、術語、基本概念 | 基礎題 |
| 理解（Understand） | 解釋、舉例、分類、摘要、推論、比較、說明 | 基礎~中等題 |
| 應用（Apply） | 在情境中執行、實施程序或方法 | 中等題 |
| 分析（Analyze） | 區辨、組織、歸因結構或關係 | 進階題 |

## 三、試題標註方法

### 3.1 標註程序

每道試題經由以下程序標註：

1. **編碼對應**：判斷試題考核的核心學習內容編碼
2. **認知層次判定**：依據試題答題所需認知歷程判定層次
3. **難度評估**：依據會考答對率區分基礎/中等/進階
4. **跨編碼標記**：若試題涉及多個學習內容，標註次要編碼與權重

### 3.2 標註紀錄格式

```
題號,學年度,科目,主要編碼,次要編碼,認知層次,難度等級,答對率,備註
```

### 3.3 權重計算公式

每個學習內容編碼的權重：

```
權重 = Σ（該編碼在 t 年度試題中的出現次數） / Σ（t 年度所有出現次數）

t = 近 3~5 學年度（滾動窗口）
```

## 四、決策引擎

### 4.1 教學決策

基於知識矩陣與試題權重，系統可產出：

- **高權重教學優先序**：近年頻繁出題的主題應優先教學
- **低權重檢核清單**：長期未出題的主題仍需確認是否已掌握
- **跨年度趨勢變化**：特定主題的權重變化趨勢

### 4.2 學習決策

基於知識矩陣與個人答題紀錄，系統可產出：

- **弱點定位**：在知識矩陣中標記個人弱點區域
- **學習路徑建議**：從基礎到進階的個人化學習順序
- **複習優先序**：依據出題權重與個人弱點的組合排序

## 五、模組架構

```
EDS/
├── Module A: 知識矩陣建置
│   └── 產出：五科知識矩陣（knowledge-matrix/）
│
├── Module B: 試題標註
│   ├── 輸入：歷屆會考試題
│   └── 產出：試題標註資料（exam-data/）
│
├── Module C: 權重計算
│   ├── 輸入：知識矩陣 + 試題標註
│   └── 產出：學習內容權重表
│
├── Module D: 決策產出
│   ├── 輸入：權重表（可選：個人答題紀錄）
│   └── 產出：教學建議 / 學習建議（outputs/）
│
└── Module E: 迭代更新
    └── 隨學年度更新持續擴充
```

## 六、使用場景

### 6.1 教師使用

- 備課階段的教學重點排序
- 段考命題的雙向細目表設計
- 學期末的教學反思與調整

### 6.2 學生使用

- 會考前的複習優先序制定
- 弱點診斷與針對性練習
- 學習進度的自我監控

### 6.3 教材編者使用

- 確認教材內容與課綱的對應完整性
- 調整教學活動的認知層次分布

---

## 七、與 RDQ 的關係

EDS 與 RDQ（Retrospective Daily Quiz）的關係為 **上游－下游**：

- **EDS** 負責課綱分析、試題標註、權重計算
- **RDQ** 負責日常回顧測驗、個人學習追蹤、習慣建立
- EDS Module D 的產出（權重表）可匯入 RDQ 作為複習優先序的依據
- EDS 不涉及個人學習資料，RDQ 不涉及課綱試題分析
