# EDS — Educational Decision System

**教育決策系統：從課綱到試題的垂直整合方法論**

EDS 是一套基於臺灣 108 課綱（12 年國教）的教育決策系統，涵蓋：

- **知識矩陣（Knowledge Matrix）**：五科（國文、英語、數學、社會、自然）108 課綱學習內容的結構化編碼與階層對照
- **試題分析（Exam Analysis）**：歷屆會考試題與知識點的對應標註，支援權重計算與出題趨勢分析
- **決策產出（Decision Output）**：從知識矩陣與試題分析產出對教學與學習的具體建議

## 目錄結構

```
EDS/
├── methodology/          # EDS 方法論文件
├── knowledge-matrix/     # 五科 108 課綱知識矩陣
├── exam-data/            # 歷屆試題標註資料
└── outputs/              # 分析報告與決策產出
```
